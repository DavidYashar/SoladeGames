These documents describe plans that are no longer current. They are kept because the
reasoning is still useful, not because any of it is true of the product today.

| File | What it was | Status |
|---|---|---|
| `Games-Business-Plan.md` / `.html` / `README.pdf` | Revenue model, pricing, market | **In development.** Not decided. |
| `Arcade-Economy-and-NFT-Game-Theory.md` / `.html` | Token and NFT thinking for the original design | Retired |
| `ENGINEERING.md` | Architecture of the earlier four-cabinet build | Superseded |
| `Landing-Neon-Arcade-Hall.md` | The old landing page plan | Superseded |
| `Platform-Docs.txt` | Platform notes for the Arc Testnet version | Retired |
| `GAME-RULES.md` | Rules for four cabinets, including Bubble Pop | Partly superseded |

Retired means: the plan involved our own USDC rails, a 25% NFT holder share, a 15%
platform take, Arc Testnet, and a fourth cabinet called Bubble Pop. None of that is
built, and the current direction is to run the games on Bankroll's rails and take no
cut of game revenue.

Current documentation lives one level up: [`docs/`](../) for cabinet notes, and
[`README.md`](../../README.md) for the product.
